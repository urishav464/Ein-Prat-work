# הכנת שבת — מדרשת עין פרת

מערכת קטנה שמפיקה לכל שבת **שלושה פלטים**:

1. **לו"ז צל** (PDF + PNG) — מימין הלו"ז של השבת, משמאל מי עושה מה ומתי.
2. **דף שישי לכל קבוצה** (PDF + PNG) — ההכנות והניקיונות של יום שישי בלבד.
3. **גיליון מתכלל** (`shabbatot/<תאריך>.xlsx`, מותאם לייבוא לגוגל שיטס) — לו"ז,
   משימות, קבוצות, חניכים, מתכונים ומה מגיע מהקייטרינג.

## הרעיון

**המשימה היא היחידה, לא הקבוצה.** לכל משימה יש יום, שעה, קבוצה, כמה אנשים היא
דורשת, ומי עושה אותה. גודל הקבוצה נגזר מהמשימות — **המספר הגדול ביותר של אנשים
שנדרשים בו-זמנית** — כך שאף אחד לא עומד בלי משימה. אותו אדם עושה כמה משימות
בשעות שונות; משימה בלי שעה (למשל ניקיון בסיום) = כל הקבוצה.

## הזרימה השבועית

```bash
python3 tools/new_shabbat.py 2026-09-11                 # קובץ לשבת, מהתבנית
python3 tools/new_shabbat.py 2026-09-11 --from shabbatot/2026-09-04.xlsx   # או מהשבת הקודמת
python3 tools/attendance.py 2026-09-11 < names.txt      # מי נמצא
python3 tools/assign_groups.py 2026-09-11               # שמות לכל משימה
python3 tools/export_pdf.py 2026-09-11                  # לו"ז צל + דפי שישי
```

`--from` מעביר הלאה עריכות שנעשו במשימות, במתכונים ובקייטרינג; רק השמות, הקבוצות
והשעות מתאפסים.

### עריכה בגוגל שיטס

מעלים את הקובץ לדרייב (קובץ ← ייבוא), עורכים שם, ומורידים בחזרה כ-xlsx אל
`shabbatot/<תאריך>.xlsx`. הייצוא קורא רק תאים סטטיים («שעה» ו«אירוע» ב«לוז», «שמות»
ב«משימות»), ולכן כל עריכה ידנית משתקפת בפלט.

### החלפות והצמדות

ב-`data/attendance/<תאריך>.csv`: `זמין לתורנות = לא` מוציא חניך מהתורנות השבת;
`שיבוץ ידני = <קבוצה>` מצמיד אותו לקבוצה. מוצמדים נשארים גם אם הקבוצה גדולה מהשיא.

## הגיליון

| גיליון | תוכן |
|---|---|
| **לוז** | תאריך (רשימה מ«זמנים»), כניסה/צאה, וטבלה ידנית: יום · שעה · אירוע · מקום · הערה · **הצעה**. «שעה» = מה שנשלח בפועל; «הצעה» מחושבת מכניסת/צאת השבת |
| **משימות** | יום · שעה · קבוצה · משימה · אנשים · **שמות** · עוגן בלו"ז · הערה. המקור היחיד לתורנויות |
| **קבוצות** | קבוצה · קבוצת אם · מוביל/ה · חניכים · גודל · משימות |
| **חניכים** | שם · תוכנית · זמין/ה · קבוצה השבת · הערה |
| **מתכונים** | עוגות / סלטים / מטבוחה / ארוחת צהריים שישי — למילוי חופשי |
| **קייטרינג** | מה מגיע לכל ארוחה |
| **זמנים** | לוח השבתות (ירושלים), ניתן לעריכה |

**עוגן** = האירוע ב«לוז» שלידו המשימה מופיעה בלו"ז הצל (הרשימה הנגללת נלקחת מעמודת
«אירוע»). משימה בלי עוגן מוצג בבלוק «ללא עוגן» בתחתית.

## קבצי הנתונים

| קובץ | תוכן |
|---|---|
| `data/task_library.csv` | המשימות הקבועות: יום, שעה, קבוצה, משימה, אנשים, עוגן. מאכלס את «משימות» בתבנית |
| `data/group_plan.csv` | המבנה הקבוע: קבוצה, קבוצת אם, מוביל/ה, חברים קבועים |
| `data/schedule_template.csv` | שורות הלו"ז וכלל ההצעה לכל שורה (בסיס כניסה/צאה/קבוע + היסט בדקות) |
| `data/students.csv` | רשימת החניכים (שם, תוכנית) |
| `data/attendance/<תאריך>.csv` | נוכחות, זמינות והצמדות לשבת |
| `data/duty_history.csv` | מי היה תורן מתי — עדיפות למי שלא היה |
| `data/zmanim.csv` | זמני כניסה/צאה (`tools/zmanim.py`) |

## הסקריפטים

| סקריפט | תפקיד |
|---|---|
| `tools/build_workbook.py` | בונה את התבנית `shabbat-planner.xlsx` מהקבצים ב-`data/` (רק כשמשנים מבנה) |
| `tools/new_shabbat.py` | קובץ לשבת: תאריך, שעות סטטיות לפי התבנית, ניקוי שמות |
| `tools/attendance.py` | קליטת רשימת נוכחים עם התאמת שמות |
| `tools/assign_groups.py` | גודל לפי שיא, שיבוץ לקבוצות (הצמדות ← מובילים ← אלול מפוזר ← השאר), ושמות לכל משימה |
| `tools/export_pdf.py` | לו"ז צל ודפי שישי דרך Chromium |
| `tools/zmanim.py`, `tools/roster.py`, `tools/fetch_fonts.py` | זמנים, רשימת חניכים, פונטים |

```
shabbat-planner.xlsx          ← התבנית
shabbatot/<תאריך>.xlsx        ← הגיליון של השבת
shabbatot/<תאריך>/לוז צל.pdf  ← ועוד דף שישי לכל קבוצה (pdf + png)
```
