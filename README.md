# תכנון שבת — מדרשת עין פרת

מערכת להכנת שבתות הקמפוס: לוח זמנים שנגזר לבד מזמני כניסת/צאת השבת, חלוקת החניכים
לקבוצות עם כרטיסייה מודפסת לכל אחת, רשימת קניות שמחושבת מהמתכונים, וצ'קליסט לוגיסטי.

**הקובץ לשימוש: [`shabbat-planner.xlsx`](shabbat-planner.xlsx)** — פותחים באקסל, ממלאים,
מדפיסים. קובץ לשבת מסוימת נמצא ב-[`shabbatot/`](shabbatot).

---

## מה עושים כל שבוע

| # | גיליון | מה עושים |
|---|--------|----------|
| 1 | **הגדרות** | בוחרים תאריך שבת — הזמנים נטענים לבד. ממלאים מרחבים ואנשי צוות |
| 2 | **חניכים** | משבצים כל חניך לקבוצה (או נותנים לסקריפט לשבץ לפי מבנה הקבוצות) |
| 3 | **שיבוץ** | מי עושה מה: קבוצה, חלון זמן, שעה, משימה, פרטים ועוגן בלו"ז |
| 4 | **תפריט השבת** | אילו מנות מכינים וכמה מכל אחת |
| 5 | הדפסה | **לוז** · **כרטיסיות** · **לו"ז צל** · **טופס נקי** · **צ'קליסט** · **קניות** |

מה שנשלח לחניכים: **כרטיסיות** (דף לכל קבוצה) ו**לו"ז צל** (מה קורה מתי, מאחורי
הקלעים). מונה הכיסוי בראש לו"ז הצל מוודא שכל משימה מופיעה באחד משניהם.

צבע הטאב מספר מה כל גיליון: 🟠 כתום = ממלאים · 🔵 כחול = פלט להדפסה · ⚪ אפור = מאגרים.

## מבנה הקבוצות — `data/group_plan.csv`

המבנה מוגדר בקובץ אחד ולא בקוד, כך שהוא נשמר משבוע לשבוע ושינוי שלו הוא עריכת שורה:

| קבוצה | קבוצת אם | גודל | מוביל/ה | חברים קבועים | ערכת צבע | תחומי אחריות |
|---|---|---|---|---|---|---|
| עוגות · צוות רותם | עוגות | 3 | רותם דרור | | ורוד | |
| בית מדרש · קידוש | בית מדרש ופינת קפה | 5 | | | ים | `שבת:קידוש` |

**קבוצת אם** מאגדת תת-קבוצות תחת קבוצה אחת — למשל «בית מדרש ופינת קפה» שמתחלקת לארבע
תת-קבוצות של חמישה (ארוחת ערב · טיש · קידוש · צהריים בשבת). **תחומי אחריות** הם
`חלון:תחום` מתוך «מאגר משימות», ומהם נבנות שורות השיבוץ אוטומטית — כולל השעה
והעוגן שמוגדרים לכל משימה במאגר.

## מי תורן בכל שבת

שלוש רשימות עובדות יחד:

- **`data/attendance/<תאריך>.csv`** — מי נמצא, עמודת «זמין לתורנות» למי שלא משתתף
  (למשל חצי מחניכי אלול, שיהיו תורנים בשבת הבאה), ועמודת «שיבוץ ידני» שמצמידה חניך
  לקבוצה מסוימת. ההצמדה גוברת על כל שיקול אחר, ולכן היא גם הדרך לשמר שיבוץ קיים
  בין הרצות ולשנות בו רק מה שצריך
- **`data/group_plan.csv`** — כמה מקומות יש בכל קבוצה
- **`data/duty_history.csv`** — מי היה תורן ומתי

כשיש יותר זמינים ממקומות, השיבוץ מעדיף את מי שהיה תורן הכי מעט — כך שהעומס מתאזן
לאורך השנה מעצמו. חניכי תוכנית אלול מתפזרים יחסית לגודל הקבוצות ולא מצטברים באחת.

## ארבע קטגוריות משימה

- **אפייה ובישול** — משתנות בכל שבת לפי התפריט והמתכונים
- **ניקיון וסידור** — משימה נפרדת לכל מרחב (בית מיכאל, חדר אוכל, שירותי חדר אוכל, מטבח,
  חדר מקררים, קוביה…), כדי לבחור בכל שבת אילו מרחבים מנקים ומתי
- **תורנות ארוחה** — קידוש, ארוחות, סעודה שלישית, טיש
- **אחריות טכנית** — פלטות, מיחמים, תנור חימום, הבדלה, אורות ומזגנים, עיתון

הקטגוריה נטענת אוטומטית ב«שיבוץ» ומופיעה בכרטיסייה, כך שכל חניך רואה מיד מאיזה סוג
המשימה שלו.

## לו"ז צל

הפורמט המוכר: מימין מה שקורה בפועל (קידוש, סעודה, טיש), משמאל מי מכין את זה ומתי.

כל שורה נבנית לבד מגיליון «שיבוץ» בנוסח `10:00 · הכנסת מאפים לתנור חימום — קבוצה 1
(עוגות שמרים)`. השיוך נעשה דרך עמודת **«עוגן בלו"ז»**: בוחרים לאיזה אירוע המשימה
שייכת (17 עוגנים — ארבעה לפני שבת ושלושה-עשר אירועי הלו"ז), והיא מופיעה בדיוק מולו.
העוגן מגיע מוכן מהמאגר ואפשר לשנות אותו.

בראש הגיליון מונה: כמה משימות יש, כמה עוגנו, וכמה נותרו בלי עוגן. משימה בלי עוגן
מופיעה בבלוק «ללא עוגן» בתחתית — כך שום דבר לא נופל בין הכרטיסיות ללו"ז הצל.

## איך הקניות מחושבות

```
מצרכים (קטלוג: יחידה · קטגוריה · מלאי קבוע?)
   ↓
מתכונים (מנה → מרכיב → כמות ליחידה אחת)      ← ממלאים פעם אחת
   ↓ × כמות מהתפריט
תפריט השבת (מנה + כמה)                        ← העבודה השבועית
   ↓
קניות (מה לקנות)  +  לבדוק במטבח (מלאי קבוע)
```

מצרך המסומן «מלאי קבוע = כן» לא נכנס לרשימת הקניות אלא לגיליון «לבדוק במטבח», שאומר
כמה צריך ממנו השבת מול הרף שהוגדר. כל מה שלא עובר דרך מתכון — פירות לקידוש, חלב,
פיצוחים לטיש — נרשם בעמודת «תוספת ידנית».

## איך הלו"ז מחושב

הכל נגזר משתי שעות: כניסת השבת וצאתה.

| פעילות | חישוב |
|---|---|
| קבלת שבת ישראלית | שעה לפני כניסת השבת |
| קבלת שבת וערבית | 15 דק' אחרי הכניסה · בית מיכאל |
| סעודת שבת | שעה וחצי אחרי תחילת קבלת שבת, ולא לפני 18:30 · חדר אוכל |
| טיש | שעה וחצי אחרי תחילת הסעודה |
| קידוש / חבורות / צהריים | 11:00 · 11:45 · 12:30 |
| חבורה עם איש צוות | 15:00 · בית מיכאל |
| סעודה שלישית | שעה וחצי לפני צאת השבת |
| הבדלה | צאת השבת |
| ניקיונות וארגון | 10 דק' אחרי צאת השבת |
| כריכה לכריכה | כשעתיים אחרי צאת השבת, מעוגל לחצי שעה |

כשנשארת פחות משעה בין החבורה של 15:00 לסעודה שלישית מופיעה התראה כתומה ב«לוז» — זו
הנקודה שדורשת החלטה.

## הסקריפטים

```bash
python3 tools/roster.py                       # רשימת חניכים מ-data/ ← data/students.csv
python3 tools/attendance.py 2026-09-04 < names.txt   # מי נמצא בשבת הזו
python3 tools/build_workbook.py               # בניית shabbat-planner.xlsx מחדש
python3 tools/new_shabbat.py 2026-09-04        # קובץ שבת ← shabbatot/2026-09-04.xlsx
python3 tools/assign_groups.py 2026-09-04     # שיבוץ לפי מבנה הקבוצות
python3 tools/export_pdf.py 2026-09-04         # פליירים + לו"ז צל ← PDF ו-PNG
python3 tools/zmanim.py 2027-09-01 2028-08-31  # לוח שבתות לשנה חדשה
python3 tools/fetch_fonts.py                   # פונטים לפליירים (פעם אחת)
```

**`export_pdf.py`** מפיק את מה שנשלח בפועל לחניכים: פלייר לכל קבוצה (PDF + PNG
לוואטסאפ) ואת לו"ז הצל כ-PDF. קבוצה עם תת-קבוצות מקבלת פלייר אחד עם מקטע לכל
תת-קבוצה, ואם זה צפוף מדי לעמוד — פלייר נפרד לכל תת-קבוצה. הפלייר בנוי בעיצוב הפוסטרים — צבע לפי ערכת הקבוצה,
פס זמנים של השבת, שם המוביל/ה, חבילת האחריות, רשימת החניכים והמשימות עם שעה
וקטגוריה. אם התוכן גולש, העמוד מותאם אוטומטית כדי להישאר עמוד אחד. הנתונים נקראים
מקובץ השבת עצמו, כך שגם עריכות ידניות באקסל משתקפות בפלייר.

**`attendance.py`** קולט רשימת שמות מודבקת (מספור ותווי רשימה מותרים), מתאים כל שם
לשם הקנוני גם כשהכתיב שונה — «הלל פיינגולד» ← «הלל פינגולד», «שחר מרקוביץ'» ←
«שחר מרקוביץ' גליק» — ומדווח על שמות שלא זוהה ועל מי שאינו נוכח. רק הנוכחים נכנסים
לתורנויות.

**`assign_groups.py`** משבץ לפי `group_plan.csv`: קודם המובילים והחברים הקבועים
שצוינו בשמם, אחר כך חניכי אלול (מפוזרים יחסית), ולבסוף השאר — לפי מי שהיה תורן הכי
מעט. התוצאה נכתבת לגיליונות «חניכים», «קבוצות» ו«שיבוץ», ונרשמת ב-`duty_history.csv`.
הכל הצעה — אפשר לערוך ידנית באקסל, והפליירים ייבנו מהעריכה.

עריכת התוכן הקבוע אפשרית משני הכיוונים — ישירות באקסל, או בקבצי ה-CSV ואז בנייה מחדש.
שינוי ישירות באקסל **נמחק** בבנייה מחדש, לכן שינוי שרוצים לשמור כדאי להעביר גם ל-CSV.

תלויות לבנייה מחדש: `pip install openpyxl pyluach`. הפקת ה-PDF משתמשת ב-Chromium
שכבר מותקן בסביבה — אין צורך בהתקנה נוספת.
