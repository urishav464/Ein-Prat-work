# הכנת שבת — מדרשת עין פרת

מערכת קטנה שמפיקה לכל שבת **שלושה תוצרים**:

1. **פלייר לכל קבוצת עבודה** (PDF + PNG) — השמות, המשימות עם שעה ומי, ולצוות הכנה גם המתכון.
2. **לו"ז צל** (PDF + PNG) — מימין הלו"ז של השבת, משמאל מי עושה מה ומתי.
3. **הגיליון המתכלל** (`shabbatot/<תאריך>.xlsx`, מותאם לייבוא לגוגל שיטס) — הטופס שמאחורי הכל.

## הרעיון

**המשימה היא היחידה, לא הקבוצה.** לכל משימה יש שלב, יום, שעה, קבוצה, כמה אנשים היא
דורשת, ניקוד, ומי עושה אותה. גודל הקבוצה נגזר מהמשימות — **המספר הגדול ביותר של אנשים
שנדרשים בו-זמנית** — כך שאף אחד לא עומד בלי משימה. משימה בלי שעה = כל הקבוצה.

**שלושה שלבים** מסדרים את השבת, וחניך יכול להיות בקבוצה אחת בכל שלב (עוגה בבוקר שישי
וגם תורנות ארוחת ערב):

| שלב | מה | מתי |
|---|---|---|
| הכנות שישי | צוותי הכנה לפי מנה — חומוס, עוגות, מטבוחה... | שישי בוקר |
| תורנות שישי | סידור וניקיון: בית מדרש, חדר אוכל | שישי צהריים–אחה"צ |
| תורנות שבת | ארוחת ערב, טיש, קידוש, ארוחת צהריים | ליל שבת ושבת |

**מעקב עומס:** לכל משימה ניקוד (1 רגיל · 2 קשה · 3 קשה מאוד). הניקוד נצבר ב«חניכים»
ונשמר ב«היסטוריה»; מי שצבר פחות משובץ קודם, וחניכי אלול מתפזרים בין הקבוצות.

## הזרימה השבועית

```bash
python3 tools/new_shabbat.py 2026-09-18                 # קובץ לשבת, מהתבנית
python3 tools/new_shabbat.py 2026-09-18 --from shabbatot/2026-09-04.xlsx   # או מהשבת הקודמת
python3 tools/attendance.py 2026-09-18 < names.txt      # מי נמצא
python3 tools/assign_groups.py 2026-09-18               # שמות לכל משימה
python3 tools/export_pdf.py 2026-09-18                  # לו"ז צל + פלייר לכל קבוצה
```

`--from` מעביר הלאה עריכות שנעשו במשימות, במתכונים ובקייטרינג; רק השמות, הקבוצות
והשעות מתאפסים. «היסטוריה» תמיד נשמרת.

### עריכה בגוגל שיטס

מעלים את הקובץ לדרייב (קובץ ← ייבוא), עורכים שם, ומורידים בחזרה כ-xlsx אל
`shabbatot/<תאריך>.xlsx`. הייצוא קורא רק תאים סטטיים («שעה» ו«אירוע» ב«לוז», «שמות»
ב«משימות», המתכונים), ולכן כל עריכה ידנית משתקפת בפלט.

### החלפות והצמדות

ב-`data/attendance/<תאריך>.csv`: `זמין לתורנות = לא` מוציא חניך מהתורנות השבת;
`שיבוץ ידני = <קבוצה>` מצמיד אותו לקבוצה (כמה קבוצות משלבים שונים — מופרדות ב-`;`).
מוצמדים נשארים גם אם הקבוצה גדולה מהשיא.

## הגיליון

צבעים אחידים בכל הגיליונות: **צהוב** = ממלאים · **טורקיז** = הסקריפט כותב · **אפור** = מחושב.

| גיליון | תוכן |
|---|---|
| **לוח בקרה** | תאריך, כניסה/צאה, פאנל מצב (נוכחים · זמינים · בתורנות · משימות בלי שמות · בלי עוגן...) וסדר העבודה |
| **לוז** | יום · שעה · אירוע · מקום · הערה · הצעה · משימות. «שעה» = מה שנשלח; «הצעה» מחושבת מכניסה/צאה; «משימות» = כמה מעוגנות לאירוע |
| **משימות** | שלב · יום · שעה · קבוצה · משימה · אנשים · שמות · מתכון · ניקוד · עוגן · הערה. המקור היחיד לתורנויות |
| **קבוצות** | קבוצה · שלב · מוביל/ה · חניכים · גודל · משימות — פלייר לכל שורה |
| **חניכים** | שם · תוכנית · זמין/ה · קבוצות השבת · משימות השבת · ניקוד השבת · ניקוד מצטבר · הערה |
| **היסטוריה** | תאריך · שם · שלב · קבוצה · משימה · ניקוד — רשומה לכל משימה, מכל השבתות |
| **מתכונים** | קטגוריה · מנה · כמות · מרכיבים · הוראות · הערה. המנה נבחרת ב«משימות» ומודפסת על הפלייר |
| **קייטרינג** | מה מגיע לכל ארוחה |
| **זמנים** | לוח השבתות (ירושלים), ניתן לעריכה |

**עוגן** = האירוע ב«לוז» שלידו המשימה מופיעה בלו"ז הצל. משימה בלי עוגן מוצגת בבלוק
«ללא עוגן» בתחתית.

## קבצי הנתונים

| קובץ | תוכן |
|---|---|
| `data/task_library.csv` | המשימות הקבועות: שלב, יום, שעה, קבוצה, משימה, אנשים, מתכון, ניקוד, עוגן. מאכלס את «משימות» בתבנית |
| `data/group_plan.csv` | המבנה הקבוע: קבוצה, שלב, מוביל/ה, חברים קבועים |
| `data/schedule_template.csv` | שורות הלו"ז וכלל ההצעה לכל שורה (בסיס כניסה/צאה/קבוע + היסט בדקות) |
| `data/students.csv` | רשימת החניכים (שם, תוכנית) |
| `data/attendance/<תאריך>.csv` | נוכחות, זמינות והצמדות לשבת |
| `data/duty_history.csv` | רשומה לכל משימה של כל חניך, עם ניקוד — הזיכרון של המערכת |
| `data/zmanim.csv` | זמני כניסה/צאה (`tools/zmanim.py`) |

## הסקריפטים

| סקריפט | תפקיד |
|---|---|
| `tools/build_workbook.py` | בונה את התבנית `shabbat-planner.xlsx` מהקבצים ב-`data/` (רק כשמשנים מבנה) |
| `tools/new_shabbat.py` | קובץ לשבת: תאריך, שעות סטטיות לפי התבנית, ניקוי שמות |
| `tools/attendance.py` | קליטת רשימת נוכחים עם התאמת שמות |
| `tools/assign_groups.py` | שלב אחרי שלב: גודל לפי שיא, שיבוץ לפי ניקוד (הצמדות ← מובילים ← השאר), שמות לכל משימה, היסטוריה |
| `tools/export_pdf.py` | לו"ז צל ופלייר לכל קבוצה דרך Chromium |
| `tools/zmanim.py`, `tools/roster.py`, `tools/fetch_fonts.py` | זמנים, רשימת חניכים, פונטים |

```
shabbat-planner.xlsx          ← התבנית
shabbatot/<תאריך>.xlsx        ← הגיליון של השבת
shabbatot/<תאריך>/לוז צל.pdf  ← ועוד פלייר לכל קבוצה (pdf + png)
```
