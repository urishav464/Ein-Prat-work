# תכנון שבת — מדרשת עין פרת

מערכת להכנת שבתות הקמפוס: לוח זמנים שנגזר לבד מזמני כניסת/צאת השבת, וחלוקת תורנויות
לקבוצות עם כרטיסייה מודפסת לכל קבוצה.

**הקובץ לשימוש: [`shabbat-planner.xlsx`](shabbat-planner.xlsx)** — פותחים באקסל, ממלאים,
מדפיסים. אין צורך בשום דבר אחר.

---

## מה עושים כל שבוע (5 דקות)

| # | גיליון | מה עושים |
|---|--------|----------|
| 1 | **הגדרות** | בוחרים תאריך שבת מהרשימה — כניסת השבת וצאתה נטענות אוטומטית |
| 2 | **הגדרות** | ממלאים מרחבים (קבלת שבת ישראלית, קידוש, חבורות, טיש, סעודה שלישית) ואנשי צוות |
| 3 | **לוז** | מוכן. כל השעות נגזרו לבד — רק להדפיס |
| 4 | **קבוצות** | מעדכנים הרכבים (רק כשהם משתנים) |
| 5 | **שיבוץ** | קובעים מי עושה מה: קבוצה, חלון זמן, משימה מהרשימה, וכמויות בעמודת הפרטים |
| 6 | **כרטיסיות** / **טופס נקי** | מדפיסים. צבעוני לוואטסאפ, נקי לתלייה בחדר אוכל |

בסיום: *קובץ ← שמירה בשם ← «שבת פרשת ___»*, וכך נשמר תיעוד לכל שבת.

### קובץ מוכן לשבת מסוימת

במקום לבחור תאריך ידנית אפשר להפיק קובץ שכבר מכוון לשבת הרצויה:

```bash
python3 tools/new_shabbat.py 2026-09-04                       # ← shabbatot/2026-09-04.xlsx
python3 tools/new_shabbat.py 2026-09-04 --clear-groups \
        --clear-assignments --clear-settings                  # פתיחת שנה / הרכב חדש
```

הקבצים נשמרים בתיקיית `shabbatot/` — היסטוריה של כל השבתות במקום אחד.

## איך הלו"ז מחושב

הכל נגזר משתי שעות: כניסת השבת וצאתה.

| פעילות | חישוב |
|---|---|
| קבלת שבת ישראלית | שעה לפני כניסת השבת |
| קבלת שבת וערבית | 15 דק' אחרי כניסת השבת · בית מיכאל |
| סעודת שבת | שעה וחצי אחרי תחילת קבלת שבת, ולא לפני 18:30 · חדר אוכל |
| טיש | שעה וחצי אחרי תחילת הסעודה |
| קידוש / חבורות / צהריים | 11:00 · 11:45 · 12:30 |
| חבורה עם איש צוות | 15:00 · בית מיכאל |
| סעודה שלישית | שעה וחצי לפני צאת השבת |
| הבדלה | צאת השבת |
| ניקיונות וארגון | 10 דק' אחרי צאת השבת |
| כריכה לכריכה | כשעתיים אחרי צאת השבת, מעוגל לחצי שעה כלפי מעלה |

בשבתות חורף, כשנשארת פחות משעה בין החבורה של 15:00 לסעודה שלישית, מופיעה בגיליון «לוז»
התראה כתומה — זו בדיוק הנקודה שדורשת החלטה על שינוי.

## אם שינית שם של קבוצה

שמות הקבוצות ב«שיבוץ» הם טקסט, ולא מתעדכנים לבד כששם משתנה ב«קבוצות». עמודת **«בדיקה»**
בגיליון «שיבוץ» מדליקה אזהרה כתומה על כל שורה שמפנה לקבוצה שאינה קיימת — התיקון הוא
חיפוש והחלפה בעמודת הקבוצה.

## זמני השבתות

גיליון «זמנים» ממולא מראש לשנה קדימה לפי ירושלים: כניסה 40 דק' לפני השקיעה, צאה 40 דק'
אחריה. הדיוק הוא דקה-שתיים. **הלוח שאתה עובד לפיו הוא הקובע** — אפשר לתקן כל שורה
בגיליון (השדות הצהובים), או להזין עקיפה חד-פעמית ב«הגדרות».

לחישוב מחדש לשנים אחרות, או לשינוי ההיסטים:

```bash
python3 tools/zmanim.py 2027-09-01 2028-08-31   # מעדכן data/zmanim.csv
python3 tools/build_workbook.py                 # בונה מחדש את shabbat-planner.xlsx
```

ההיסטים (`CANDLE_MINUTES_BEFORE_SUNSET`, `HAVDALAH_MINUTES_AFTER_SUNSET`) מוגדרים בראש
`tools/zmanim.py`.

## מבנה הפרויקט

```
shabbat-planner.xlsx        התוצר — הקובץ שעובדים איתו
tools/build_workbook.py     מחולל החוברת (openpyxl)
tools/zmanim.py             חישוב זמני ירושלים
data/zmanim.csv             לוח השבתות
data/task_library.csv       מאגר המשימות הקבוע
data/groups_sample.csv      הרכבי הקבוצות ההתחלתיים
```

עריכת התוכן הקבוע (משימות, קבוצות) אפשרית משני הכיוונים: ישירות באקסל, או בקבצי ה-CSV
ואז בנייה מחדש. שינוי ישירות באקסל **נמחק** בבנייה מחדש — לכן שינוי שרוצים לשמור לאורך
זמן כדאי להעביר גם ל-CSV.

תלויות לבנייה מחדש: `pip install openpyxl pyluach`.

## מה עוד מתוכנן (שלב ב')

רשימת קניות אוטומטית: מתכונים וכמויות לפי מספר משתתפים, הפרדה בין מצרכים שקונים לבין
מלאי קבוע במטבח שרק צריך לוודא, ורשימה מסודרת לסמדר. וכן צ'קליסט לוגיסטי (פלטות,
מיחמים, ציוד הבדלה, אורות ומזגנים, עיתון השבת).
