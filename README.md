# הכנת שבת — מדרשת עין פרת

מערכת קטנה שמפיקה לכל שבת **שלושה תוצרים**:

1. **פלייר לכל קבוצת עבודה** (PDF + PNG) — השמות, והמשימות עם שעה, הערה ומי.
   פלייר ארוך מתכווץ מעט כדי להישאר עמוד אחד.
   לקבוצות ההכנה מודפסת גם **רשימת המצרכים** של המנה (כמות, מרכיבים והערה) —
   בלי אופן ההכנה; `--with-recipes` מוסיף גם אותו.
2. **לו"ז צל** (PDF + PNG) — מימין הלו"ז של השבת, משמאל מי עושה מה ומתי.
   ארוך מדי לעמוד אחד? הוא מתחלק לעמודים שלמים, ולכל עמוד תמונה נפרדת
   (`לוז צל 1.png`, `לוז צל 2.png`) — נוח לשלוח.
3. **הגיליון המתכלל** (`shabbatot/<תאריך>.xlsx`, מותאם לייבוא לגוגל שיטס) — הטופס שמאחורי הכל.

## הרעיון

**המשימה היא היחידה, לא הקבוצה.** לכל משימה יש שלב, יום, שעה, קבוצה, כמה אנשים היא
דורשת, ניקוד, ומי עושה אותה. גודל הקבוצה נגזר מהמשימות — **המספר הגדול ביותר של אנשים
שנדרשים בו-זמנית** — כך שאף אחד לא עומד בלי משימה. משימה בלי שעה = כל הקבוצה.

**ארבעה שלבים** מסדרים את השבת, וחניך יכול להיות בקבוצה אחת בכל שלב (עוגה בבוקר שישי
וגם תורנות ארוחת ערב):

| שלב | מה | מתי |
|---|---|---|
| הכנות שישי | **משתנות כל שבוע** — מה שהאחראים בחרו (חלות, עוגות, סלטים…) + ארוחת צהריים שישי | שישי בוקר |
| תורנות שישי | סידור בית המדרש, ועזרה להכנות ב-10:00 לפי מה שהאחראים ביקשו | שישי |
| תורנות שבת | ארוחת ערב · טיש · קידוש · ארוחת צהריים שבת | ליל שבת ושבת |
| תורנות מוצ"ש | ניקיון בית המדרש · ניקיון חדר האוכל · ארוחת ערב מוצ"ש | מוצאי שבת |

חניך יכול להיות בכמה שלבים, **כל עוד השעות לא מתנגשות** — מי שמסדר את בית המדרש
ב-8:00 לא ייפול גם לצוות הכנה באותה שעה.

**מעקב עומס:** לכל **תורנות** ניקוד לפי הקושי שלה — **3** הכנות שישי, בית מדרש וארוחת
ערב מוצ"ש וניקיון חדר האוכל · **2** ארוחת ערב וארוחת צהריים שבת וניקיון בית המדרש ·
**1** טיש וקידוש. החניך
מקבל את הניקוד פעם אחת לכל תורנות; הוא נשמר ב«היסטוריה», ומי שצבר פחות משובץ קודם.

**צוות שבת קבוע** (עמודת «צוות שבת» ב-`data/students.csv`): מעיין רחל דינר, עמרי קולטון,
יובל יצחק, חיים שמאי, איתמר אסנהיים, הילה לביא. מי מהם שנוכח משמש **אחראי/ת** על
קבוצה שסומנה `אחראי מצוות` ב-`group_plan.csv` (ארבע תורנויות השבת), נספר בתוך גודל
הקבוצה, ואינו ממלא מקומות רגילים בקבוצות אחרות.

## השבוע שלך — האחראים ממלאים, פקודה אחת עושה את השאר

1. האחראים מקבלים את **`docs/מדריך לאחראי שבת.png`** — מה לבדוק במהלך השבוע — וממלאים
   את **`טופס שבת.md`**: מי בשבת, מה מכינים (כמה, כמה אנשים, מי אחראי), מה מוגש, מוצ"ש.
2. הטופס נכנס לשלושה קבצים לתאריך, ולשורה ביומן:

| קובץ | תוכן |
|---|---|
| `data/attendance/<תאריך>.csv` | נוכחים; `לא זמין בשלב` למי שלא בשישי / עוזב לפני מוצ"ש; הצמדות |
| `data/preps/<תאריך>.csv` | שורה לכל משימה: הכנה · יום · שעה · משימה · כמות · אנשים · אחראי · עזרה מבית המדרש · מתכון · הערה |
| `data/menu/<תאריך>.csv` | מה מוגש בכל «ארוחה»: קייטרינג (ארוחת ערב, ארוחת צהריים, סלטים), מה מההכנות (מההכנות לערב / לצהריים), חלוקת העוגות (טיש, קידוש, סעודה שלישית) |
| `data/weeks.csv` | `שבת משותפת = כן` כששנה א' איתנו — רק אז נכנסות הערות «שנה ב'» |

3. פקודה אחת:

```bash
python3 tools/shabbat.py 2026-10-16            # תבנית ← שיבוץ ← פליירים ולו"ז צל ← zip ← בדיקות
python3 tools/shabbat.py 2026-10-16 --check    # רק בדיקות ו-zip על מה שכבר קיים
python3 tools/guide.py                         # מדפיס מחדש את המדריך לאחראים
```

בסוף הריצה נוצר `shabbatot/<תאריך>/פליירים <dd.mm>.zip` עם כל התמונות, ומודפסות
הבדיקות: אף אחד לא בשני מקומות באותה שעה, חסומים לא בשלב שממנו נחסמו, לכל חבר
יש משימה, לכל קבוצה שצריכה אחראי יש אחראי, כל משימה מעוגנת ללו"ז, וכל פלייר
בעמוד אחד. חסר קובץ — הפקודה עוצרת ואומרת מה.

**איך ההכנות נכנסות:** הכנה שאינה קבוצה קבועה הופכת לקבוצה חדשה עם פלייר (3 נקודות).
שורה של קבוצה קבועה (ארוחת צהריים שישי, ארוחת ערב מוצ"ש, הניקיונות) **מחליפה** את
המשימה הקבועה שלה באותו יום ושעה — כך משנים מה מבשלים או כמה מנקים. «עזרה מבית
המדרש = N» מוסיפה לבית המדרש משימה ב-10:00.

**התפריט במקום אחד:** משימה שכתוב בה `{ארוחת ערב}` מקבלת את המנות של אותה «ארוחה»
בתפריט. `{טיש|העוגות}` — אם אין לטיש שורות, נכתב «העוגות». הערה שמתחילה ב-`[משותפת]`
נשארת רק בשבת משותפת.

## הזרימה השבועית, צעד צעד

```bash
python3 tools/new_shabbat.py 2026-09-18                 # קובץ לשבת, מהתבנית
python3 tools/new_shabbat.py 2026-09-18 --from shabbatot/2026-09-04.xlsx   # או מהשבת הקודמת
python3 tools/attendance.py 2026-09-18 < names.txt      # מי נמצא
python3 tools/assign_groups.py 2026-09-18               # שמות לכל משימה
python3 tools/export_pdf.py 2026-09-18                  # לו"ז צל + פלייר לכל קבוצה
python3 tools/export_pdf.py 2026-09-18 --with-recipes   # גם אופן ההכנה על הפלייר
```

`--from` מעביר הלאה עריכות שנעשו במשימות, במתכונים ובקייטרינג; רק השמות, הקבוצות
והשעות מתאפסים. «היסטוריה» תמיד נשמרת.

### עריכה בגוגל שיטס

מעלים את הקובץ לדרייב (קובץ ← ייבוא), עורכים שם, ומורידים בחזרה כ-xlsx אל
`shabbatot/<תאריך>.xlsx`. הייצוא קורא רק תאים סטטיים («שעה» ו«אירוע» ב«לוז», «שמות»
ב«משימות», המתכונים), ולכן כל עריכה ידנית משתקפת בפלט.

### החלפות והצמדות

ב-`data/attendance/<תאריך>.csv`:
- `זמין לתורנות = לא` — מוציא חניך מהתורנות השבת.
- `לא זמין בשלב = הכנות שישי;תורנות שישי` — מוציא אותו משלב מסוים בלבד. כך שומרי
  ליל חמישי לא קמים ב-8:00, ומי שמגיע רק בשבת עדיין נכנס לתורנויות השבת.
- `שיבוץ ידני = <קבוצה>` — מצמיד לקבוצה (כמה קבוצות משלבים שונים מופרדות ב-`;`).
  מוצמדים נשארים גם אם הקבוצה גדולה מהשיא, והשעות והניקוד של ההצמדה נשמרים להם
  כבר בשלבים המוקדמים — מי שהוצמד לבית מדרש לא יילקח קודם להכנה ב-8:00.
- `אחראי על = <קבוצה>` — מצמיד לקבוצה **וגם** רושם כאחראי/ת שלה (על הפלייר ובלו"ז
  הצל). עובד גם לחניכים וגם לאנשי צוות; קבוצה עם אחראי/ת כזה לא מקבלת אחראי מהצוות
  אוטומטית.
- `צוות שבת = כן` — מוסיף איש צוות לשבת הזו בלבד (הצוות הקבוע כבר ב-`students.csv`).

## הגיליון

צבעים אחידים בכל הגיליונות: **צהוב** = ממלאים · **טורקיז** = הסקריפט כותב · **אפור** = מחושב.

| גיליון | תוכן |
|---|---|
| **לוח בקרה** | תאריך, כניסה/צאה, פאנל מצב (נוכחים · זמינים · בתורנות · משימות בלי שמות · בלי עוגן...) וסדר העבודה |
| **לוז** | יום · שעה · אירוע · מקום · הערה · הצעה · משימות. «שעה» = מה שנשלח; «הצעה» מחושבת מכניסה/צאה; «משימות» = כמה מעוגנות לאירוע |
| **משימות** | שלב · יום · שעה · קבוצה · משימה · אנשים · שמות · מתכון · עוגן · הערה. המקור היחיד לתורנויות; «מתכון» יכול להחזיק כמה מנות מופרדות ב-`;` |
| **קבוצות** | קבוצה · שלב · ניקוד · אחראי/ת · חניכים · גודל · משימות — פלייר לכל שורה |
| **חניכים** | שם · תוכנית · חבורה · זמין/ה · קבוצות השבת · משימות השבת · ניקוד השבת · ניקוד מצטבר · הערה |
| **היסטוריה** | תאריך · שם · שלב · קבוצה · ניקוד — רשומה לכל תורנות של כל חניך, מכל השבתות |
| **מתכונים** | קטגוריה · מנה · כמות · מרכיבים · הוראות · הערה. המנה נבחרת ב«משימות»; המצרכים מודפסים על הפלייר, ההוראות רק עם `--with-recipes` |
| **קייטרינג** | מה מוגש בכל ארוחה — נטען מ-`data/menu/<תאריך>.csv` |
| **זמנים** | לוח השבתות (ירושלים), ניתן לעריכה |

**עוגן** = האירוע ב«לוז» שלידו המשימה מופיעה בלו"ז הצל. משימה בלי עוגן מוצגת בבלוק
«ללא עוגן» בתחתית.

## קבצי הנתונים

| קובץ | תוכן |
|---|---|
| `data/task_library.csv` | המשימות הקבועות (בלי ההכנות, שמשתנות). «שעה» יכולה להיות יחסית לאירוע העוגן (`-30`, `+0`), כך שמשימות הטיש והסעודה זזות איתם: שלב, יום (חמישי/שישי/שבת/מוצאי שבת), שעה, קבוצה, משימה, אנשים, מתכון, עוגן, הערה. מאכלס את «משימות» בתבנית |
| `data/recipes.csv` | המתכונים: קטגוריה, מנה, כמות, מרכיבים, הוראות, הערה. מאכלס את «מתכונים», ונשמר משבת לשבת |
| `data/group_plan.csv` | הקבוצות הקבועות (ההכנות מתווספות מ-`preps`): קבוצה, שלב, ניקוד, אחראי מצוות, מוביל/ה, חברים קבועים |
| `data/schedule_template.csv` | שורות הלו"ז וכלל ההצעה לכל שורה: בסיס (כניסה / צאה / קבוע / **שם של אירוע אחר**) + היסט בדקות + «עיגול» (כלפי מעלה, בדקות). סעודת שבת = כניסה + 105 לרבע השעה הבאה; טיש = סעודת שבת + 90 |
| `data/students.csv` | רשימת החניכים (שם, תוכנית, צוות שבת) |
| `data/attendance/<תאריך>.csv` | נוכחות, חבורה, זמינות, אי-זמינות לשלב והצמדות |
| `data/preps/<תאריך>.csv` | ההכנות שהאחראים בחרו לשבת |
| `data/menu/<תאריך>.csv` | מה מוגש בכל ארוחה: קייטרינג, מההכנות, חלוקת העוגות |
| `data/weeks.csv` | שורה לכל שבת: האם משותפת עם שנה א' |
| `data/duty_history.csv` | רשומה לכל תורנות של כל חניך, עם ניקוד — הזיכרון של המערכת |
| `data/zmanim.csv` | זמני כניסה/צאה (`tools/zmanim.py`) |
