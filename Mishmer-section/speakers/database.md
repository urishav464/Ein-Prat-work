## שמות שצריך לאמת

| מה הבעיה | הפרטים |
|---|---|
| **לימור ויסברט / לימור וייסברד** | אותה אדם בשתי כתיבים? והסטטוס סותר: `✅ יכולה` במשמר פילוסופיית המזרח, `❌ לא יכולה` באלול. אם זו אותה אדם — איזה סטטוס נכון? |
| **גבריאלה לוי / גבריאלה לווי** | שני כתיבים, ככל הנראה אותה אדם |
| **דוד נחמן / ד״ר דוד נחמן** | אותו אדם, עם ובלי תואר |
| **ירון ויסברג / מנחם וייסברג** | אותו שם משפחה, שם פרטי שונה — שני אנשים או שגיאת קריאה? |
